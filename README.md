# 手写数字识别系统

一个基于PyTorch和Tkinter的手写数字识别应用程序，支持手绘数字识别和图片上传识别。

## 功能特点

### 🎨 手绘画板功能
- 交互式手绘画板，支持鼠标绘制数字
- 可调节画笔大小和颜色
- 一键清空画板功能
- 支持多次连续识别（修复了画板多次识别问题）

### 📷 图片上传功能
- 支持常见图片格式（PNG, JPG, JPEG, BMP, GIF）
- 实时图片预览
- 智能图片预处理和反色处理

### 🤖 智能识别功能
- 基于CNN神经网络的高精度识别
- 实时显示识别结果和置信度
- 提供Top-3预测结果及置信度
- 支持CPU/GPU自动切换

### 📊 模型管理
- 灵活加载不同的.pth模型文件
- 支持状态字典和完整模型对象
- 实时显示模型加载状态和设备信息

## 系统要求

### 硬件要求
- **内存**: 至少2GB RAM
- **存储**: 至少500MB可用空间
- **显卡**: 支持CUDA的NVIDIA GPU（可选，用于加速）

### 软件要求
- **操作系统**: Windows 10/11, macOS, Linux
- **Python**: 3.7 或更高版本
- **依赖包**: 详见 requirements.txt

## 安装指南

### 1. 克隆或下载项目
```bash
git clone <项目地址>
cd tool
```

### 2. 安装Python依赖
```bash
pip install -r requirements.txt
```

主要依赖包：
- `torch>=1.9.0`: PyTorch深度学习框架
- `torchvision>=0.10.0`: 计算机视觉库
- `Pillow>=8.3.0`: 图像处理库
- `numpy>=1.21.0`: 数值计算库
- `matplotlib>=3.4.0`: 数据可视化库

### 3. 准备模型文件

#### 选项A：使用预训练模型（推荐）
项目已包含预训练模型：
- `models/test_model.pth`: 状态字典格式（轻量级）
- `models/test_model_full.pth`: 完整模型对象格式

#### 选项B：训练新模型
```bash
python train_mnist.py
```

训练参数（可调整）：
- `--epochs`: 训练轮数（默认10）
- `--batch_size`: 批次大小（默认64）

- `--save_path`: 模型保存路径（默认models/mnist_model.pth）

示例：
```bash
python train_mnist.py --epochs 15 --batch_size 128 --save_path models/my_model.pth
```

## 快速开始

### 启动应用程序
```bash
python src/main.py
```

或直接运行：
```bash
python -m src.main
```

### 基本使用流程
1. **启动程序**: 运行上述命令打开GUI界面
2. **加载模型**: 点击"选择模型文件"，选择.pth文件，然后点击"加载模型"
3. **手绘识别**:
   - 在左侧画板上绘制数字（0-9）
   - 点击"识别手绘数字"
   - 查看右侧识别结果
4. **图片识别**:
   - 点击"选择图片"上传数字图片
   - 点击"识别上传数字"
   - 查看识别结果
5. **多次识别**: 清空画板或选择新图片，重复识别操作

## 详细使用方法

### 1. 模型加载区域
- **选择模型文件**: 浏览并选择.pth格式的模型文件
- **加载模型**: 加载选中的模型文件到内存
- **卸载模型**: 从内存中移除当前模型
- **模型状态**: 显示当前模型加载状态（未加载/已加载/加载失败）
- **设备信息**: 显示当前使用的计算设备（CPU/CUDA）

### 2. 手绘画板区域
- **绘制数字**: 在白色画板上使用鼠标绘制0-9的数字
- **画笔设置**:
  - 画笔大小：通过数值调节器调整（1-30）
  - 画笔颜色：固定为黑色（针对MNIST数据集优化）
- **控制按钮**:
  - **清空画板**: 清除画板上所有内容
  - **识别手绘数字**: 对当前画板内容进行识别

### 3. 图片上传区域
- **图片格式**: 支持PNG, JPG, JPEG, BMP, GIF格式
- **图片预览**: 上传后显示缩略图预览
- **控制按钮**:
  - **选择图片**: 浏览并选择数字图片文件
  - **识别上传数字**: 对上传的图片进行识别
  - **清除图片**: 清除当前预览的图片

### 4. 识别结果区域
- **主要结果**: 显示识别出的数字（0-9）
- **置信度**: 显示识别置信度百分比
- **详细信息**: 显示Top-3预测结果及各自置信度
- **颜色指示**:
  - 绿色: 置信度 > 90%（高置信度）
  - 蓝色: 置信度 70%-90%（中等置信度）
  - 橙色: 置信度 < 70%（低置信度）

### 5. 状态栏
- 显示当前操作状态和提示信息
- 实时反馈加载、识别等操作进度

## 模型选择标准

### 模型格式说明
系统支持两种PyTorch模型格式：

#### 1. 状态字典格式（.pth）
- **文件大小**: 较小（通常几百KB到几MB）
- **加载方式**: 需要匹配的模型架构
- **推荐场景**: 项目内部使用，已知模型架构
- **示例**: `models/test_model.pth`

#### 2. 完整模型对象格式（.pth）
- **文件大小**: 较大（包含模型架构和参数）
- **加载方式**: 直接加载完整模型对象
- **推荐场景**: 模型共享，未知模型架构
- **示例**: `models/test_model_full.pth`

### 模型性能评估标准

#### 1. 准确率指标
- **测试准确率**: >95%为优秀，>90%为良好
- **训练准确率**: 应与测试准确率相近（避免过拟合）
- **Top-3准确率**: 应接近100%

#### 2. 模型大小考量
- **小型模型**: <5MB，适合快速加载和部署
- **中型模型**: 5-50MB，平衡准确率和速度
- **大型模型**: >50MB，最高准确率，但加载较慢

#### 3. 推理速度
- **CPU推理**: 单次识别 < 100ms 为优秀
- **GPU推理**: 单次识别 < 10ms 为优秀

### 预训练模型选择建议

#### 场景1：快速体验和测试
- **推荐模型**: `models/test_model.pth`
- **优点**: 文件小，加载快，准确率足够
- **适用**: 功能测试、快速演示

#### 场景2：生产环境部署
- **推荐模型**: 自定义训练的高准确率模型
- **训练建议**:
  - 训练轮数: 15-20 epochs
  - 批次大小: 128-256
  - 学习率: 0.001-0.0005
  - 数据增强: 可添加旋转、缩放等增强

#### 场景3：研究或定制需求
- **推荐模型**: 基于特定需求训练的专业模型
- **定制方向**:
  - 特定字体风格的数字
  - 不同背景颜色的图片
  - 特定应用场景的优化

### 模型兼容性检查

系统会自动检测模型兼容性，但建议：

1. **架构匹配**: 确保模型与MNISTCNN架构兼容
2. **输入尺寸**: 模型应接受28x28灰度图像输入
3. **输出维度**: 模型应输出10个类别的概率分布
4. **PyTorch版本**: 建议使用PyTorch 1.9+训练的模型

## 故障排除

### 常见问题及解决方案

#### 1. 模型加载失败
**问题**: "模型加载失败"或"状态字典与模型架构不匹配"
**解决方案**:
- 检查模型文件路径是否正确
- 确认模型格式（状态字典或完整模型）
- 尝试使用`models/test_model.pth`测试
- 检查PyTorch版本兼容性

#### 2. 画板识别失败
**问题**: 画板上绘制数字后识别失败或结果错误
**解决方案**:
- 确保画板上有足够的笔画（避免过细或过淡）
- 绘制完整的数字，避免断笔
- 清空画板后重新绘制
- 检查控制台输出中的图像统计信息

#### 3. 图片上传识别失败
**问题**: 上传图片后识别失败或结果错误
**解决方案**:
- 确保图片包含清晰的数字（0-9）
- 图片背景应简洁，避免复杂背景
- 数字颜色应与背景有明显对比
- 尝试调整图片大小（建议100x100像素以上）

#### 4. 多次识别问题（已修复）
**问题**: 画板只能识别一次，清空后再次绘制无法识别
**解决方案**:
- ✅ 此问题已在最新版本中修复
- 系统现在支持无限次连续识别
- 确保使用最新版本的`src/image_processor.py`

#### 5. 性能问题
**问题**: 识别速度慢或界面卡顿
**解决方案**:
- 关闭其他占用资源的程序
- 如有NVIDIA GPU，确保CUDA已正确安装
- 减少同时进行的识别任务

```python
# 修改训练参数
epochs = 20           # 增加训练轮数
batch_size = 128      # 调整批次大小
learning_rate = 0.0005 # 调整学习率

# 添加数据增强
transform = transforms.Compose([
    transforms.RandomRotation(10),      # 随机旋转
    transforms.RandomAffine(0, translate=(0.1, 0.1)), # 随机平移
    transforms.ToTensor(),
    transforms.Normalize((0.1307,), (0.3081,))
])
```
